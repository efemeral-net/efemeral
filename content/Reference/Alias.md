tags:

---
Set up in alias as a `CLI` shortcut.

### Temporary

```bash 
alias SpecialFolder="cd /path/to/Special_Folder"
```
### Permanent

#### Bash / Linux
```bash
echo 'alias SpecialFolder="cd /path/to/Special_Folder' >> ~/.bashrc 
```
#### Zsh / Mac
```bash
echo 'alias SpecialFolder="cd /path/to/Special_Folder' >> ~/.zshrc
```
